# ☕ HotBeans Coffee Shop Website

HotBeans is a Coffee Shop Management Website developed using PHP, MySQL, HTML, CSS, JavaScript and XAMPP.

The project provides a user-friendly coffee ordering system where users can browse coffee products, place orders and book tables. It also includes an admin panel for managing products, orders, contacts and users.

## Features

### User Side Features

- User Registration and Login
- Browse Coffee Products
- View Coffee Menu
- Add Products
- Place Coffee Orders
- Book Tables
- Contact Form
- Blog Section
- Gallery Section

### Admin Panel Features

- Dashboard
- Manage Orders
- Manage Contact
- Manage Tables
- Add Product
- Edit Product
- View Product
- Register User Management

## Technologies Used

## Installation Steps

### 1 Clone Repository

git clone https://github.com/YOUR_USERNAME/HOTBEANS.git

### 2 Move Project Folder

Copy project folder into:

C:\xampp\htdocs\

Final path:

C:\xampp\htdocs\hotbeans

### 3 Start XAMPP

Open XAMPP Control Panel

Start:

- Apache
- MySQL

### 4 Import Database

Open:

http://localhost/phpmyadmin

Create database:

hotbeans

Import:

hotbeans.sql

### 5 Run Project

Main Website:

http://localhost/hotbeans/

Admin Panel:

http://localhost/hotbeans/admin/login.php

## Customer Ordering Process

1. User opens the HotBeans website.

2. Customer browses coffee products from menu section.

3. User selects coffee items.

4. Customer places order.

5. Order information is stored in MySQL database.

6. Admin receives order details in admin panel.

7. Admin manages order status.

8. Customer receives coffee order successfully.
